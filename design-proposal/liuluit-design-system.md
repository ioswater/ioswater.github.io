# LiuLuit 技术文档站 · 界面设计系统

> 设计方向：**科技深色 + 明暗双主题**，品牌一致性优先，强调"有意图"的克制而非满屏发光。
> 主色取自站点 favicon 渐变（青 `#22d3ee` → 蓝绿 `#0ea5a1` → 蓝 `#1d4ed8`），与现有品牌资产严格一致。

---

## 1. 设计目标

| 维度 | 要求 |
|------|------|
| 美观 | 近黑蓝背景而非纯黑、冷调中性灰、品牌渐变作点睛，避免"AI 套路感" |
| 易用 | 顶部导航 + 侧边栏 + 右侧 TOC 的经典文档信息架构，新访客 3 秒定位 |
| 习惯 | 沿用 Starlight 用户的既有心智（搜索、主题切换、目录），不颠覆 |
| 一致 | 单一 accent 色（10% 占比），组件状态可追溯，token 驱动 |

---

## 2. 色彩系统（OKLCH）

> 采用 OKLCH 而非 HSL —— 感知均匀，明暗阶梯不会"偏色"。
> 中性灰全部**冷调着色**（chroma 极小，hue≈250），与品牌色潜意识呼应。

### 暗色主题（默认）

| Token | OKLCH | 角色 |
|-------|-------|------|
| `--bg` | `oklch(15% 0.028 255)` | 页面背景（近黑蓝，非纯黑） |
| `--surface-1/2/3` | `18.5% / 22% / 26%` | 卡片 / 面板 / 凸起层级 |
| `--border` | `oklch(82% 0.02 255 / .12)` | 发丝分割线 |
| `--text-strong` | `oklch(98% 0.01 250)` | 标题 |
| `--text` | `oklch(90% 0.015 250)` | 正文 |
| `--text-muted` | `oklch(72% 0.02 250)` | 次要信息 |
| `--accent` | `oklch(74% 0.14 195)` | 主强调（CTA / 链接 hover / 焦点环） |
| `--glow` | `oklch(74% 0.14 195 / .22)` | 克制光晕（仅 Hero 角落一处） |
| `--success/warning/error` | `155 / 85 / 25` hue | 语义反馈 |

### 亮色主题

| Token | OKLCH | 说明 |
|-------|-------|------|
| `--bg` | `oklch(98.5% 0.004 250)` | 浅冷灰白 |
| `--surface-1` | `oklch(100% 0 0)` | 纯白卡片 |
| `--accent` | `oklch(54% 0.13 195)` | 降饱和，保证对比度 |
| `--text` | `oklch(31% 0.02 250)` | 深灰蓝正文（对比度 ≥ 4.5:1） |

**品牌渐变**：`linear-gradient(135deg, oklch(85% 0.13 195), oklch(65% 0.12 185) 56%, oklch(52% 0.20 258))`
用于 Logo、主按钮填充、代码卡描边——**仅作点睛，不铺满整页**。

## 3. 字体系统

| 角色 | 字体 | 替代默认 | 用途 |
|------|------|----------|------|
| 展示 / 标题 | **Space Grotesk** | 弃用 Inter | H1–H4、Logo、数字 |
| 正文 | **Instrument Sans** | 比 Inter 有个性 | 段落、UI 文本 |
| 等宽 | **JetBrains Mono** | — | 代码、标签、元信息 |

- 字号：模块化比例（perfect fourth 1.333）—— `xs .75 / sm .875 / base 1 / lg 1.25 / xl 1.667 / 2xl 2.222 / 3xl+ clamp()`
- 正文固定 `rem` 比例（文档站/数据界面不用流体字号）；仅 Hero 大标题用 `clamp()` 流式。
- 深色背景下正文 `line-height: 1.65`（浅色文字需更多呼吸感）。

---

## 4. 间距与圆角

- 基准 **4px**：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`（`--space-1`…`--space-9`）
- 用**变化的间距**制造节奏（Hero 紧凑、分区间距大），不"万物皆卡片"。
- 圆角：`--r-sm 8 / md 12 / lg 16 / xl 24`
- 动效时长 **100/300/500 规则**，缓动统一 `cubic-bezier(0.16,1,0.3,1)`（expo-out），**禁止回弹**。
- 仅动画 `transform` / `opacity`；入场用 stagger（每项 +70ms，上限 ~500ms）。

---

## 5. 组件规范（状态可追溯）

| 组件 | 默认 | Hover | Focus | Disabled |
|------|------|-------|-------|----------|
| **主按钮** | 品牌渐变填充 | 上移 2px + 阴影增强 | 焦点环 2px accent | 透明度 .6 + 禁点 |
| **次按钮** | 表面色 + 边框 | 边框加深 + 上移 | 同上 | 同上 |
| **搜索框** | 表面色 + 发丝边 | — | 边框 accent + 3px soft 环 | — |
| **卡片** | 表面色 + 发丝边 | 上移 4px + 阴影 | 焦点环 | — |
| **导航链接** | 次要文字色 | 文字提亮 + 表面底色 | 焦点环 | — |

**交互原则**
- 渐进式披露，空状态有引导文案（非"暂无数据"了事）。
- 同一页面主按钮 ≤ 1 个，避免所有按钮都"主要"。

---

## 6. 可访问性（WCAG AA）

- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1；占位符文字亦达标。
- 焦点环 `2px accent + 3px offset`，键盘可达全部功能。
- 触控目标 ≥ 44px（导航/按钮 padding 保证）。
- `prefers-reduced-motion` 下关闭位移动画，仅保留淡入。
- 语义标签：`header / nav / main / article / aside / footer` + `skip-link`。
- 不依赖纯颜色传达信息（状态配文字/图标）。

---

## 7. 落地到现有 Starlight 体系

现有项目已用 `--color-primary` / `--color-dark` 等变量驱动 `global.css` 的 Starlight token。
**推荐做法**：

1. 把上方 OKLCH 值写入 `src/styles/global.css` 的 `:root` 与 `[data-theme="light"]`，替换现有 `--color-primary` 等。
2. 字体：在 `global.css` 顶部引入 Space Grotesk / Instrument Sans，并在 `--font-display` / `--font-body` 映射。
3. 组件级微调（卡片 hover、代码块高亮）可通过现有 `components.css` / `button.css` 增补，保持 token 单一来源。
4. 原型文件 `liuluit-ui-prototype.html` 为**自包含参考实现**，可直接对照还原，主题切换逻辑已写好可复用。

> ⚠️ 合并/部署注意：按项目约定，`master` 根目录为构建产物。源码改在 `codex/dockit-source` 分支，用 `npm run deploy:github-pages` 发布，勿直接提交 `master`。
