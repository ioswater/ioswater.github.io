## 部署上线 + 修复强调色覆盖
- 用户一句话"部署"→ 直接跑 `npm run deploy:github-pages`（`env -u` 绕过 safe-delete），两轮均 DEPLOY_OK：master 推送 da64822..f40215c（首轮）、f40215c..新提交（修复轮）。
- **QA 发现坑**：首轮部署后线上强调色仍是 Starlight 默认蓝，非方案的 #22d3ee。根因：Vite 把 `global.css` 并进 `ThemeSwitch.*.css`，该 chunk 在 HTML 中排在 `common.*.css`（Starlight 自带，含 `--sl-color-accent:hsl(224,100%,60%)` 默认蓝）**之前**，后加载即覆盖我的 `--sl-color-accent:var(--color-primary)`。字体/标题/渐变都不在 common.css 重定义，故正常；仅 accent 三件套被覆盖。
- **修复**：global.css 的 `:root` 与 `:root[data-theme="light"]` 里给 `--sl-color-accent` / `-low` / `-high` 加 `!important`（lightningcss 保留自定义属性 !important），无视打包顺序稳赢。二次构建部署后线上确认含 `--sl-color-accent:var(--color-primary)!important`。
- 源码提交：4 个源文件提交到 `codex/dockit-source`（commit f19f398），`.workbuddy/` 与 `design-proposal/` 保留未跟踪。master 仅部署提交，符合"源码在 codex"约定。
